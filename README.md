## Repository Structure
The repository is organized into two main directories:

/doc: Contains UML diagrams and technical documentation created during the 3rd semester.

/src: Contains the source code for four key projects, each representing a different stage and focus in my learning journey.


---

## Projects Overview

### [Programming](/src/Programming)
**2nd Semester**

**Tech Stack**: C#, Windows Forms, MVC Pattern

This was my first significant project in the "Programming" course. The goal was to build a language-learning application while getting acquainted with Windows Forms. A key learning objective was the separation of concerns, which I implemented using a Model-View-Controller (MVC) architecture.

**Key Concepts:** Windows Forms UI, Basic C# Syntax, Event Handling, Model-View-Controller (MVC) Separation.

### [AirTravelList](/src/AirTravelList) 
**2nd Semester** 

**Tech Stack**: C#, Windows Forms, Technical Documentation

An individual project assigned to consolidate knowledge from the second semester. It involved developing a complete application from an individual variant, followed by the creation of formal technical documentation. This project emphasized not just coding, but the full software development lifecycle.

**Key Concepts:** Independent Problem Solving, Application Development, **Technical Documentation**

### [ObjectOrientedPractics](/src/ObjectOrientedPractics)
**3rd Semester**

**Tech Stack**: C#, Windows Forms

A project for the "Object-Oriented Programming" course focused on deeply understanding and applying core OOP principles. The application simulates an e-commerce system for managing product purchases.

**Key Concepts:** 
- **OOP Pillars:** Inheritance, Polymorphism, Encapsulation
- **Object Relationships:** Composition, Aggregation
- **C# Features:** .NET Interfaces, Delegates, Events

### [Contacts](/src/Contacts)
**4th Semester**

**Tech Stack**: C#, WPF, MVVM Pattern

The most advanced project, developed for the "Object-Oriented Analysis and Design" course. It marks a significant technological step forward, transitioning from Windows Forms to the more modern and powerful Windows Presentation Foundation (WPF).

**Key Concepts:** 
- **Modern UI:** WPF with XAML
- **Architecture:** **Model-View-ViewModel (MVVM)** for clean separation of UI and business logic.
- **Workflow:** **Git Pull Requests**
- **Design:** Object-Oriented Analysis & Design
